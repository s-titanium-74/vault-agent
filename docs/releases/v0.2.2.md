# vault-agent v0.2.2

## Changes

- Add a dedicated READWRITE credential for MCP editing over HTTP on local
  servers and Cloudflare Workers. It grants retrieval and, when writes are
  enabled, the three MCP change tools. Indexing, uploads and other management
  operations still require ADMIN. See [#74](https://github.com/s-titanium-74/vault-agent/pull/74).
- Allow explicitly configured direct MCP writes for pCloud Markdown notes on
  both runtimes. Direct mode uses `preview_changes` with `preview:false` to
  allocate an operation ID, then `apply_changes` with that ID and identical
  operations. Writes remain disabled by default, and review remains the default
  mode when enabled. pCloud's revision check and write are separate operations,
  so use one writer for the configured folder. See
  [#75](https://github.com/s-titanium-74/vault-agent/pull/75).
- Restore local search for pCloud notes edited at the source after an MCP edit.
  The next successful index refresh also repairs existing visibility records,
  including when the newer revision was already indexed. Deletions and pending
  or unresolved writes retain their visibility protection. The equivalent
  Workers/D1 search issue was reproduced separately. See
  [#77](https://github.com/s-titanium-74/vault-agent/pull/77).

## Installation

- Docker image `namka0703/vault-agent:0.2.2`.
- The npm workspaces are versioned at 0.2.2. Publication of
  `@vault-agent/cli`, `@vault-agent/core`, and `@vault-agent/server` to the npm
  registry is pending registry authentication.
- Local source builds require Node.js 22 or newer. Cloudflare Workers use a
  separate deployment.

See the [local setup guide](https://github.com/s-titanium-74/vault-agent/blob/v0.2.2/docs/setup-guide.md)
and [Cloudflare setup guide](https://github.com/s-titanium-74/vault-agent/blob/v0.2.2/docs/cloudflare-setup-guide.md).
