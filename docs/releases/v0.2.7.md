# vault-agent v0.2.7

## Changes

- Local `index` and `reindex` on Linux recover stale index locks when the
  operating system has reused the writer's PID. Locks with a live or uncertain
  owner still return `INDEX_BUSY`.
- Concurrent writers coordinate through a vault-scoped SQLite lock, so only
  one writer can recover a stale lock and proceed.
- Existing indexes are reused. Stop old writer processes before upgrading.

See [#94](https://github.com/s-titanium-74/vault-agent/issues/94) and
[#95](https://github.com/s-titanium-74/vault-agent/pull/95).

## Installation

- Docker image tag `namka0703/vault-agent:0.2.7` (Linux AMD64).
- npm package versions `@vault-agent/cli@0.2.7`, `@vault-agent/core@0.2.7`,
  and `@vault-agent/server@0.2.7`.
- Local source and npm installations require Node.js 22 or newer.

See the [local setup guide](https://github.com/s-titanium-74/vault-agent/blob/v0.2.7/docs/setup-guide.md).
